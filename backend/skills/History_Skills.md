# History Skills

Overview
- History skills focus on critical analysis of primary and secondary sources, chronology, and constructing evidence-based arguments about the past.

Core Topics
- Source Analysis and Corroboration
- Historical Context and Chronology
- Comparative and Thematic History
- Historical Argumentation and Writing

Learning Objectives
- Students can analyze primary sources for perspective, bias, and reliability.
- Students can construct a short historical essay supported by evidence.

Suggested Activities
- Document-based questions (DBQs), timeline construction, roleplay debates, research projects.

Assessment Ideas
- Source analysis essays, research projects, presentations, short-response prompts.

Resources
- Archives, curated source collections, library databases, history textbooks and documentaries.

Teaching Guide for Tutor Agent
- Purpose: Enable the agent to teach historical thinking, source analysis, and evidence-based argumentation.

Instructional Flow
- Diagnostic: Provide a short primary source excerpt and ask initial observations.
- Source Analysis: Guide students to assess provenance, perspective, and reliability.
- Argument Construction: Help students build claims supported by sourced evidence.

Scaffolding Strategies
- Use guided questions (who, what, when, why, how) and provide sentence frames for arguments.

Sample Agent Prompts
- "Read this excerpt and list three things it reveals about the period and one question it raises." 
- "Draft a one-paragraph argument answering: What was the main cause of X? Include two pieces of evidence."

Assessment & Feedback
- Rubrics for source use, clarity of arguments, and evidence integration.
