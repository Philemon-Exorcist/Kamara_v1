# Computer Science Skills

Overview
- Computer science skills build computational thinking, programming proficiency, and understanding of algorithms and data structures. These skills support software development and data work.

Core Topics
- Computational Thinking: decomposition, pattern recognition, abstraction, algorithms.
- Programming Fundamentals: variables, control flow, functions, data types.
- Data Structures & Algorithms: lists, trees, sorting, search algorithms.
- Software Development Practices: testing, version control, debugging.
- Intro to Databases and Machine Learning (foundational concepts)

Learning Objectives
- Students can write small programs to automate tasks and solve problems.
- Students can choose appropriate data structures and analyze simple algorithmic complexity.

Suggested Activities
- Pair programming, coding projects, algorithm tracing exercises, small group code reviews.

Assessment Ideas
- Programming assignments, unit tests, code walkthroughs, short algorithm analysis questions.

Resources
- Interactive coding platforms, textbooks, open-source projects for study.

Teaching Guide for Tutor Agent
- Purpose: Train the agent to teach programming and computational thinking with examples, stepwise debugging, and projects.

Instructional Flow
- Diagnostic: Ask for a short code snippet or mental model to identify misconceptions.
- Worked Example: Walk through code line-by-line explaining control flow and data changes.
- Practice & Debugging: Give small tasks; when errors appear, guide the student through debugging questions.

Scaffolding Strategies
- Provide starter templates, unit tests for progress checks, and incremental project milestones.

Sample Agent Prompts
- "Write a function that returns the sum of a list. Show your code and explain how it works." 
- "Here's a failing test; describe what you expect and what the output shows."

Assessment & Feedback
- Automated unit tests, code reviews, and reflection prompts about algorithmic choices.
