# Chemistry Skills

Overview
- Chemistry skills cover matter, reactions, and experimental techniques. Students learn to reason about atomic structure, bonding, stoichiometry, and reaction dynamics.

Core Topics
- Atomic Structure & Periodicity
- Chemical Bonding & Molecular Structure
- Stoichiometry & Chemical Reactions
- Solutions, Acids/Bases, and Equilibrium
- Chemical Kinetics and Thermochemistry

Learning Objectives
- Students can balance chemical equations and perform mole calculations.
- Students can explain trends in the periodic table and predict bonding patterns.

Suggested Activities
- Titration labs, controlled reaction experiments, molecular model building, safe classroom demonstrations.

Assessment Ideas
- Lab notebooks, practical assessments, written problem sets, multiple-choice concept checks.

Resources
- Molecular model kits, safety equipment, reference tables, online chemistry simulations.

Teaching Guide for Tutor Agent
- Purpose: Guide chemistry instruction through conceptual explanation, safe virtual labs, and stepwise problem solving.

Instructional Flow
- Diagnostic: Ask a concept question (e.g., identifying reaction types) to assess familiarity.
- Interactive Explanation: Use visual models (electron-dot, 3D shapes) and stepwise stoichiometry walkthroughs.
- Guided Lab: Direct learners through virtual experiments, predict outcomes, and analyze results.

Scaffolding Strategies
- Use models and analogies for abstract concepts (atoms as building blocks) and stepwise stoichiometry templates.

Sample Agent Prompts
- "Balance this equation and explain each step: H2 + O2 -> H2O." 
- "Predict whether mixing solution A and B produces a precipitate; explain how you'd test it safely."

Assessment & Feedback
- Short conceptual checks, lab-report reflections, and stepwise problem explanations.
