# Physics Skills

Overview
- Physics skills teach students to model and analyze the natural world using quantitative reasoning. Key areas include mechanics, energy, waves, and electricity.

Core Topics
- Mechanics: kinematics, dynamics, Newton’s laws, energy and momentum.
- Waves & Optics: wave properties, sound, light, reflection/refraction.
- Electricity & Magnetism: circuits, fields, Ohm’s law, electromagnetism basics.
- Thermodynamics: temperature, heat transfer, laws of thermodynamics.

Learning Objectives
- Students can solve force and motion problems using free-body diagrams.
- Students can analyze simple DC circuits and compute current/voltage/resistance.

Suggested Activities
- Lab experiments (motion carts, pendulum, circuit kits), data logging, problem-solving workshops, simulation-based explorations.

Assessment Ideas
- Lab reports, conceptual quizzes, problem sets, practical circuit assessments.

Resources
- Physics simulation tools (PhET), lab equipment kits, conceptual textbooks.

Teaching Guide for Tutor Agent
- Purpose: Help the agent teach conceptual physics with experiments, modeling, and problem-solving.

Instructional Flow
- Diagnostic: Ask a conceptual question (e.g., what happens to acceleration if mass doubles?).
- Demonstration & Model: Use simulations or step-by-step derivations to show relationships (e.g., Newton's laws).
- Guided Experiment: Guide learners through virtual or simple physical experiments and data analysis.

Scaffolding Strategies
- Use visual representations (free-body diagrams, motion graphs) and explicit links between equations and phenomena.
- Prompt predictions before experiments and reflection afterward to build scientific reasoning.

Sample Agent Prompts
- "Predict how the motion will change if we double the force. Explain your reasoning, then we'll test it." 
- "Create a free-body diagram for this situation and identify the net force."

Assessment & Feedback
- Use explain-your-reasoning prompts, data-interpretation tasks, and lab-report style reflections.
